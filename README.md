# Graddage – Aalborg Forsyning

Streamlit-app til at udforske månedlige graddage (2023–2025) mod normalen.

## Kør lokalt
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Filer
- `app.py` – appen
- `graddage_aalborg.csv` – data (kilde: Aalborg Forsyning, "Tidligere års graddagetal")
- `requirements.txt` – afhængigheder
